# rustify
## The one tool to convert c++ into rust (aka. peak)

Rustify is a tool that helps speed up the process when converting C++ code to rust.

## How to run
## Option A - Compile from source
You can compile this repository and compile it with
`cargo build --release`
and run the executable in `target/release`
## Option B - Download from crates.io (not yet released)
You can download this program from crate.io by running this command
`cargo install rustify`

## Why does this exist?
I got the inspiration from the meme that rust developers rewrite everything that was written in C++ in rust, so i decided to make this (written in rust btw).
This is not meant to be used standalone in production as its lacking a lot of features but instead could be used alongside an ai agent.
